# Участие в разработке LUMQERA

Спасибо за интерес к LUMQERA. Мы разрабатываем PvP/Survival-проект для Minecraft Java Edition на основе Paper 26.3 и JDK 25.

## Сообщения об ошибках и предложения

Откройте [Issues](https://github.com/Zeihos/LUMQERA/issues/new/choose) и выберите русскоязычный шаблон. Приложите точную версию сервера, действия для воспроизведения и ожидаемый результат.

**Не публикуйте** игровые миры игроков, личные данные, токены, приватные IP-адреса, закрытые административные журналы и настройки с секретами.

## Перед отправкой изменений

1. Создайте отдельную ветку от main.
2. Вносите точечные изменения. Не добавляйте JAR, логи, базы данных, игровые миры или IDE-файлы.
3. Для ядра используйте JDK 25 и Gradle 9.1.0:
   
       cd server/LumqeraCore
       gradle clean build --no-daemon

4. Для сайта проверьте:

       node --check website/app.js
       node --check website/dev-server.mjs
       node --test tests/website-smoke.test.mjs

5. В pull request объясните, что изменено, как проверяли и какие ограничения остались.

**Важно:** прохождение автоматической сборки не доказывает работу игровых механик на настоящем Paper-сервере.

Лицензия на использование исходного кода пока не опубликована. Публичная доступность репозитория сама по себе не означает разрешения на свободное копирование и распространение.
