# LUMQERA · проверка игровых защит RC12

**Версия ядра:** 1.0.0-RC12  
**Среда:** Minecraft Java / Paper 26.3 / Java 25

Этот документ — план ручной проверки, а **не отчёт о пройденных тестах**. Проверку необходимо выполнить на запущенном Paper с несколькими игроками. Прежде чем тестировать, полностью остановите сервер и сделайте резервную копию папок мира и `plugins/LumqeraCore/`.

## Подготовка

1. Установите JAR RC12 из успешного запуска GitHub Actions при полностью остановленном Paper.
2. Запустите сервер, проверьте в консоли, что загружен `LumqeraCore 1.0.0-RC12`.
3. Подключите минимум два разных аккаунта Minecraft: **А** — глава клана NOVA, **Б** — игрок без клана или глава другого клана LUNA. Дополнительно удобно использовать **В** — участника NOVA.
4. Включите `online-mode=true`, используйте белый список для закрытого тестирования.
5. Подготовьте три области: приват NOVA, ничейную территорию и безопасную зону SPAWN. В приватном чанке поставьте несколько сундуков, воронку, стойку для брони, рамку и питомца.
6. Все тесты начинайте с чистых или явно записанных условий. Укажите дату, координаты и название мира для каждого результата.

## Негативные проверки

- Убедитесь, что владелец привата может пользоваться своими механизмами: исправление не должно блокировать обычные постройки.
- Протестируйте конфликты с другими плагинами, в том числе защита от PvP, экономика, сундуки и механизмы.
- Проверьте оба варианта взаимодействия: предмет в основной руке и предмет во второй.
- Если срабатывает отказ сохранения, операции создания/удаления приватов не должны объявляться успешными.

## Как сообщить об ошибке

Откройте [Issues](https://github.com/Zeihos/LUMQERA/issues/new/choose), выберите «Ошибка в LUMQERA» и укажите: номер теста, точные шаги, ожидаемое и фактическое поведение, версию Paper и строки лога. Не публикуйте токены, личные данные игроков, приватные IP, миры или закрытые конфигурации.

**Критерий прохождения:** все необходимые пункты тестирования подтверждены на реальном сервере, существенных обходов защиты нет, повторная загрузка данных успешна. До этого RC12 остаётся кандидатом на релиз.
